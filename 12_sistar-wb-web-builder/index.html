Let AI Work for AI — Dual Web Asset Factory

Engineered within the sc intelligence-core, sistar wb : web-builder transforms every project, memo, and global reference into live, AI-indexable *sc web pages at high velocity. Following our core principle—1 Project or Issue to 2 Web Pages—all generated assets strictly adhere to master_prd.md and master_skill.md.

4-Stage Automated Pipeline

1. Unified Inputs — Submit your Memo, Target *sc Route/URL, Local Files, Google Drive URL, and Reference URLs.
2. Web Generation 1 (Original Vision Track) — Connects with Gamma API & PPTX generation, extracting visual assets to ./storage/ and building a clean *sc webpage.
3. Reference Webpage Search — Discovers and curates benchmark global webpages relevant to the project.
4. Web Generation 2 (Reverse-Engineering Track) — Deconstructs reference webpages, saves media to ./storage/, and rewrites insights into the *sc universe.
