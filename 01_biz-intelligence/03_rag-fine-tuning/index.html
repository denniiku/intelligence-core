CHAPTER 02 SIMILARITY GATING

Mandatory Cosine Similarity Gating ($\text{sim} \ge 0.82$) & Anti-Hallucination Protocol

A critical innovation of *SC RAG Fine-Tuning is the enforcement of the Strict Cosine Similarity Gating Protocol. In generic RAG architectures, models return the nearest $K$ vector chunks even if the similarity score is poor (e.g., 0.55 or 0.60), forcing the language model to synthesize an answer from irrelevant or tangential passages.

Inside *SC Intelligence-Core, our ingestion pipeline enforces an immutable threshold:

GATING LOGIC 01

Cosine Similarity Threshold ($\ge 0.82$)

When an agent queries the vector database for a tariff rate, supplier quote, or formulation recipe, only chunks with a cosine similarity score of $\text{sim} \ge 0.82$ are admitted into the prompt context window. Sub-threshold chunks are discarded automatically.

GATING LOGIC 02

Deterministic Fallback & Human Challenger Escalation

If no verified vector chunk meets the 0.82 threshold, the agent is strictly prohibited from improvising. It outputs an auditable message ("Specification unverified in current ground truth ledger") and dispatches a prioritized inquiry ticket to the regional SISTAR Challenger on Google Chat.
